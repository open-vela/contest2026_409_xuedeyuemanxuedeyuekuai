# 黄山派智能手表第一阶段设计

**目标**

在现有 OpenVela/NuttX + LVGL watchface 应用上恢复四个历史表盘的正确视觉组合和动态时间显示，并建立后续产品化所需的轻量性能基线。表盘外观沿用本地 QuickApp 历史布局和 SiFli 官方素材，不改动已确认可用的菜单、按键和复位策略。

**范围**

- Dial：官方金属刻度背景 + 时/分/秒指针。
- Mickey：米奇背景、头部、身体、眼睛和两只手臂图层；两只手臂随时间旋转。
- Digital：数字背景 + 透明数字资源 + 冒号、日期和星期。
- Sport：官方运动背景 + 动态运动指针；步数等数据保留为模拟服务提供的值。
- 选择器：每个预览必须代表完整表盘，而不是单独的米奇头部或错误背景。
- 性能：只增加低开销的帧间隔/刷新计数统计接口和日志，不在每帧打印。

**不在本阶段**

- 不实现真实音频输出、PAN/BNEP、传感器驱动或手机协议。
- 不替换 OpenVela/NuttX 为 Zephyr、FreeRTOS 或其他 RTOS。
- 不复制 GPL 项目的代码或素材；GitHub 项目只作为架构和交互参考。

**实现约束**

- 继续使用工程当前可用的 LVGL 兼容接口，优先复用官方 `lv_img_set_angle`、`lv_img_set_pivot` 的做法。
- 所有表盘图像放入独立背景/图层对象；旋转图像使用明确的旋转中心和屏幕中心定位。
- UI 线程只做图层更新和轻量格式化；模拟数据仍由现有定时器维护。
- 资源生成器是背景和预览映射的唯一来源，生成后的 `wf_data.c` 不手工修改。
- 以自动化源代码契约测试、构建和真机串口日志作为验收证据。

**验收标准**

1. 四个表盘构建函数分别引用正确背景和对应图层，且 `face_tick()` 更新所有动态指针。
2. 选择器四个预览不再使用米奇头部单图作为 Mickey 预览，Sport 预览与 Sport 背景一致。
3. 资源生成器中 `sport_bg` 映射到 `clock_rotate_bg_bg.png`，生成描述符与声明一致。
4. 现有回归测试和新增表盘契约测试全部通过，NuttX 固件构建返回 0。
5. 真机启动日志不出现资源未声明、链接失败或 LVGL 崩溃；帧统计仅按固定周期输出。
