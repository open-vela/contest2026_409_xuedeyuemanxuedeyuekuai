# 黄山派表盘产品化第一阶段 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复黄山派 OpenVela/NuttX 固件中的四个表盘，并建立可回归的资源映射和性能基线。

**Architecture:** 保留现有 `watchface_main.c` 的页面生命周期，给 `face_ui_t` 增加背景、米奇和冒号图层，使用官方 LVGL v8 兼容的图像旋转/轴心接口；资源由 `assets_gen.py` 统一生成。性能统计只在 `face_tick()` 中聚合，不改变绘制路径。

**Tech Stack:** C, NuttX/OpenVela, LVGL v8-compatible image API, Python 3 + Pillow, Python `unittest`, CMake/Ninja.

**Spec:** `docs/superpowers/specs/2026-09-04-watchface-productization-design.md`

## Global Constraints

- 保留当前 OpenVela/NuttX + LVGL 平台，不引入其他 RTOS。
- 只使用本地 QuickApp 历史素材和 SiFli 官方素材，不复制 GPL 项目代码或素材。
- 资源必须通过 `watchface_app/assets_gen.py` 生成，禁止手工修改 `watchface_app/assets/wf_data.c`。
- UI 更新保持在 LVGL 线程内，网络、文件和硬件阻塞不进入表盘刷新回调。
- 自动化测试、完整构建和真机串口检查完成后才能声称修复完成或烧录。
