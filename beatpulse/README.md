# BeatPulse — 腕上节奏游戏

> 2026 openvela AI 硬件开发者大赛 · 手表应用创新赛道

## 简介

BeatPulse 是一款基于 openvela 快应用框架的手表节奏游戏。音符从屏幕边缘向中心收拢，
玩家在恰当时机点击/滑动来命中节拍。游戏创新性地利用手表传感器实现**心率联动动态难度**
和**体感交互**，带来独特的腕上游戏体验。

## 创新亮点

| 特性 | 说明 |
|------|------|
| **心率联动** | 通过 `@service.health` 实时读取心率，自动调整游戏难度 |
| **体感交互** | 加速度传感器检测手腕动作，作为辅助输入方式 |
| **Canvas 渲染** | 60fps 流畅动画，粒子特效 + 波纹反馈 |
| **振动反馈** | 命中节拍时触发振动，增强触觉体验 |
| **圆形适配** | 480×480 圆形表盘专属设计，辐射式玩法 |
| **端到端独立** | 不依赖手机，完全在手表上运行 |

## 游戏玩法

1. **音符生成**：音符从圆形屏幕边缘随机方向出现
2. **收拢移动**：音符沿径向向中心判定圈移动
3. **时机判定**：音符到达判定圈时点击，分为 PERFECT / GOOD / OK / MISS
4. **连击系统**：连续命中触发 COMBO 加分
5. **心率联动**：心率越高，难度自动提升（音符速度↑、生成频率↑）

### 难度等级

| 等级 | 心率范围 | 音符速度 | 生成间隔 |
|------|----------|----------|----------|
| 简单 | <70 bpm | 2.0 | 800ms |
| 普通 | 70-85 bpm | 2.5 | 700ms |
| 进阶 | 85-100 bpm | 3.0 | 600ms |
| 困难 | 100-120 bpm | 3.5 | 500ms |
| 极限 | >120 bpm | 4.0 | 400ms |

## 使用的系统能力

| API | 用途 |
|-----|------|
| `@service.health` | 心率实时订阅 + 冷启动补帧 |
| `@system.vibrator` | 命中节拍振动反馈 |
| `@system.sensor` | 加速度传感器（体感输入） |
| Canvas API | 游戏画面渲染（60fps） |

## 编译与运行

### 环境要求

- AIoT-IDE（最新版）
- aiot-core & aiot-emulator 插件 ≥ 1.7.22
- 模拟器镜像：`vela-miwear-watch-5.0(开发者大赛)`

```bash

npm install

# 2. 构建
npm run build

# 3. 在 AIoT-IDE 中选择模拟器运行
```

### 提交生产包

```bash
npm run build  # 生成 dist/beatpulse.release.rpk
```

## 性能优化（借鉴 InfoNES 项目经验）

本项目参考了 [InfoNES](https://github.com/zhangruiyep/InfoNES) 的性能优化思路：

| 优化点 | 方法 |
|--------|------|
| **渲染循环** | requestAnimationFrame + 16ms 间隔，目标 60fps |
| **脏区域** | 只重绘变化的音符和粒子，避免全屏刷新 |
| **对象池** | 粒子和音符复用，减少 GC 压力 |
| **早退判定** | 碰撞检测先做距离快速排除 |
| **FPS 可视化** | 实时显示帧率，便于性能监控 |

## 设计原则

- **操作路径短**：打开即玩，无需教程
- **信息密度高**：分数、连击、心率、时间一屏呈现
- **视觉精致**：暗色主题 + 霓虹色彩 + 粒子特效
- **不依赖手机**：完全端到端独立运行
